# 09 — Mobile Security Tools

Tools included in the learning environment or evaluated for the project:

| Tool | Purpose |
|---|---|
| MobSF | Mobile application security analysis |
| JADX | APK code inspection |
| Burp Suite | Authorized web/application traffic analysis |
| OWASP ZAP | Web application security testing |
| Wireshark | Network protocol analysis |
| ADB | Android debugging |

Record the exact installation platform and version for each tool. Some tools run on the Windows host rather than directly on Android.

Only assess apps and systems you own or have explicit authorization to test.
