# 03 — Bootloader

## Recorded status: Unlocked

The Xiaomi Mi 10i bootloader was confirmed unlocked during the project.

Verification:

```bash
fastboot getvar unlocked
```

Recorded output:

```text
unlocked: yes
```

## Notes

An unlocked bootloader allows supported boot/system modifications. It can reduce the device's security posture and may affect warranty coverage or data integrity. Preserve backups and document the unlock date and method if known.

Do not publish device serial numbers.
