# NetHunter Troubleshooting

Record:
- NetHunter edition and version
- Android ROM build
- Magisk version/root status
- Kernel version
- Exact command and error output
- DNS/network status where relevant
- Final verification

Useful checks inside Kali:

```bash
whoami
uname -a
cat /etc/os-release
```

A working shell does not necessarily mean all kernel-dependent features are supported.
